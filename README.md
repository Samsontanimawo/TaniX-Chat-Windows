# TaniX Chat for Windows: download

**TaniX Chat** is Connect, the TaniX chat, in a window of its own: your chats, groups and calls with other
students, without opening the whole TaniX app. You stay signed in.

## ⬇️ Download

**[Download TaniX Chat for Windows (.exe, 115 MB)](https://github.com/Samsontanimawo/TaniX-Chat-Windows/releases/latest/download/TaniX-Chat-1.0.0-win-x64.exe)**

(Windows 10 or 11, 64-bit. All releases: [Releases](https://github.com/Samsontanimawo/TaniX-Chat-Windows/releases).
Install steps with pictures: [tanimawoai.com/chat-app.html](https://tanimawoai.com/chat-app.html#windows).)

## Install

1. Open the downloaded file `TaniX-Chat-…-win-x64.exe` (double-click it, or click it in your browser's downloads).
2. Windows may show **"Windows protected your PC"** (the app is not signed with a paid certificate yet).
   Click **More info**, then **Run anyway**.
3. Choose where to install (the default is fine) and click **Install**. No administrator password is needed.
4. Open **TaniX Chat** from the desktop or the Start menu, and sign in.

If your browser says the download "isn't commonly downloaded", choose **Keep** (in Edge: the **…** menu → **Keep** →
**Keep anyway**).

To remove it: Settings → Apps → Installed apps → TaniX Chat → Uninstall.

## Updates

The chat inside the app is the live website, so new chat features arrive by themselves. The app also **updates
itself**: when a new version comes out it downloads it quietly and asks you to **Restart now** (or it updates the
next time you close it). You stay signed in. You can also choose **Help → Check for updates**.

(`latest.yml` and the `.blockmap` file in each release are for these automatic updates; you only need the `.exe`.)
